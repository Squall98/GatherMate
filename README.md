# GatherMate

Addon de récolte pour **World of Warcraft 3.3.5a (Wrath of the Lich King)** : affiche les gisements
sur la carte. Redistribué pour le serveur **Ebonhold**.

## À quoi ça sert
GatherMate note les emplacements d'**herbes**, **minerais**, **nuages de gaz** et **bancs de poissons**
que tu récoltes, et les affiche sur la **carte du monde** et la **minicarte**. La base de données fournie
pré-remplit déjà les gisements connus, donc tu vois directement où aller récolter.

## Fonctionnalités
- Marque **automatiquement** les nœuds récoltés (herboristerie, minage, pêche, gaz).
- Affichage sur la **carte du monde** et la **minicarte**.
- **Base de données incluse** (`GatherMate_Data`) : emplacements connus déjà pré-remplis.
- Import / partage de données entre joueurs.

## Contenu (2 dossiers)
- `GatherMate` — l'addon principal (**v1.25**).
- `GatherMate_Data` — la base de données des gisements (**v1.0**).

## Version
- Addon : **v1.25** (+ base de données v1.0)
- Compatible : WoW **3.3.5a** (build 12340)

## Installation
- **Le plus simple** : via le **launcher Ebonhold** → onglet *Catalogue* → **Installer**
  (il pose les **deux dossiers** automatiquement).
- **Manuellement** : extraire `GatherMate` **et** `GatherMate_Data` dans `Interface\AddOns\`.

## Crédits
Addon original **GatherMate** (communauté WoW). Ce dépôt sert uniquement à le **redistribuer et
l'installer facilement** sur le serveur Ebonhold via le launcher.
